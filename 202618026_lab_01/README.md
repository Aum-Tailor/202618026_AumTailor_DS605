This repository contains a complete end-to-end data pipeline that extracts book data from `books.toscrape.com` using a custom Scrapy spider (`scraper.py`). The raw data (`raw_books.csv`) is preprocessed and cleaned in a Jupyter Notebook (`pipeline.ipynb`), where new features like a 'value score' are engineered. Finally, the notebook includes data visualizations (such as a word cloud and price distributions) alongside a summary report of key insights. Both the raw and finalized datasets (`cleaned_books.csv`) are provided.
